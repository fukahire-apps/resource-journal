# 育成リソースノート

Pokémon Sleepのアメ・ゆめのかけらを記録・集計する、個人制作の非公式ツールです。公式運営・関係各社とは関係ありません。

[アプリを開く](https://fukahire-apps.github.io/resource-journal/)

## Ver.1.0.0 — 初回公開

1. 編成でポケモンを登録し、チームに設定します。
2. 記録で日時・フィールドを確認して、アメやスキル・睡眠リサーチなどを記録します。
3. アメ・ゆめのかけらで集計し、履歴から訂正・削除できます。
4. 設定 → データでCSVバックアップ・復元ができます。

記録は利用中の端末・ブラウザのlocalStorageに保存されます。ログインや端末間の自動同期はありません。サイトデータの削除やプライベート閲覧に注意し、定期的にCSVバックアップを行ってください。復元は現在のデータを置き換えるため、必要なデータは先にバックアップしてください。

本番とテスト版は異なるドメインにあり、保存領域は分離されます。端末・ブラウザ・公開先をまたぐ移行にはCSVを使用してください。

出典・ライセンス・お問い合わせは、アプリの設定 → このアプリについてで確認できます。同梱コード・アイコン等の通知は [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) に保持しています。
